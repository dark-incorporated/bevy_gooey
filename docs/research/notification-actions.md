# The notification center as a journal: actions, ids, an unlogged toast

Researched 2026-11-14 for issue #103 (G-92), asked by bevy_dark_factory #442 (the editor's journal on Cmd+E becomes `notification_center`; a note that can be undone carries an Undo action).

1. **A row is a log entry with an id, buttons and a count.** `ToastLogEntry { seconds, kind, text }` stays the plain line (a public struct a host builds by literal, as `tests/toast_actions.rs` does: adding public fields would break every such literal, so none are added). The log keeps `ToastLogRecord`s: the line, an `id()` assigned by `ToastLog::push` (which returns it), a `count()` and `actions()`. A record derefs to its line, so `record.text` and `e.kind == ..` read and write as before and `entries()` is source-compatible. Ids come from a counter that is never reset (`clear` and `remove` keep it), so an id is never reused, and they survive the log being capped, so a drawn row's action still names its entry. Inputs that mean nothing are ignored: a non-finite time is 0, a count of 0, an empty action label or id and a repeated action change nothing.
2. **Rows that did not change are not respawned.** Each row carries `NotificationRow::entry()` and a copy of what it was drawn from (`NotificationRowDrawn`); `update_notification_centers` keeps a row whose entry still equals its copy (the same entity: focus, hover and scroll position stay), rebuilds one that changed, despawns one that is gone and sets the order with `replace_children`. A log that did not change writes nothing, as before.
3. **Actions are buttons, the row's words are not.** Each action is a `Role::Button` at the row's end (the words take the rest: `flex_grow`), a tab stop; its `Activate` sends the global `NotificationAction { entry, id }`. The row stays a button (the keys scroll it) and sends nothing, so a click on a line of history does not undo it. A focused button whose row goes clears focus, as a toast's does.
4. **A toast and its journal line are one entry.** `ToastBundle::unlogged()` adds no line; `logged_as(id)` adds none and names the entry (`Toast::entry()`); a plain toast logs itself and gets its id. A merged toast logs as before.
5. **`ToastKind::Note`** is a quiet receipt: a `text_muted` mark, no `! ` in its row. It is a new variant of a public enum: listed under Breaking.

Tests, real input (`tests/notification_actions.rs`): the Undo click sends the entry and id and a click on the words sends nothing; the same by Tab and Enter; a hidden centre has no stops, also for a row added while hidden; the count reads `(x3)` with the row count unchanged; unlogged and logged-as add no row; a log capped past `CAPACITY` keeps its ids and a drawn row's action names its entry; ids are never reused; unchanged rows are the same entities and only the changed one is rebuilt; an action added or taken off after the row was drawn shows; a focused button whose row goes leaves no focus on nothing; empty and non-finite inputs are ignored; a note has its own mark and no bang.
